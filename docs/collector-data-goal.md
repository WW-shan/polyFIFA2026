# 数据采集目标：为提前挂单策略回测保留原始证据

用户确认日期：2026-09-11。

目标是连续收集 Polymarket 比赛当时的完整公开盘口、公开成交及比赛上下文，用于后续分析尾段暴跌、选择比赛、入场时间、挂单价和挂单量。挂单价是待回测的参数，0.7 只是示例；采集时不按目标价、当前策略资格或赛后输赢筛选。策略盈利性不属于本轮重新论证的任务。

## 必须保留

- 比赛/联赛、主盘及子盘口、condition、token、outcome 和原始市场规则。
- WebSocket 完整买卖档位、所有数量/价格变化和原始文本帧，不只保留中间价、K 线或最低价。
- 公开成交的价格、数量、方向、源时间及本地接收时间；挂单价附近的买盘深度与成交事实分别保留。
- 比分/阶段的原始更新、源字段、接收时间、结束事件及实际结束时间。来源没给出的字段明确缺失。
- 最终支付/作废等结果，供之后关联回测；停止接单与最终结果不是同一字段。
- 发现、订阅、首次有效快照、断线、重连和无数据区间，能逐场判断是否录全。

## 后续回测要回答

针对各个比赛类别、入场窗口、价格档位和订单量，统计：是否触价、是否有相应成交、价格/深度变化持续时间、后续走势及最终结果。保留未触价、未成交和缺数据的样本，供按用户的提前挂单规则计算各组结果及期望收益。不能把 0.7 或现有世界杯策略门槛固化为采集过滤条件。

回看终场前 1/3/5/8 分钟等窗口需要可靠结束标签。因此优先全程记录可获得的比赛数据，再事后截取所需窗口。
